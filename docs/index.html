Open Sketchpad

free · runs in your browser · no sign-up

Sketch it out, roughly.

Sketchpad is a hand-drawn whiteboard for flowcharts, system diagrams, wireframes and brainstorms. Draw boxes, join them with arrows that stay attached, then save the file or export a PNG or SVG.

Start drawing See examples GitHub

  • Opens .excalidraw files
  • Works offline
  • Light and dark

How it works

From blank page to diagram

Every tool has a one-key shortcut, so once your hand learns them you rarely touch the toolbar.

  1. Pick a shape and drag

    Rectangles, diamonds, ellipses, lines and the pencil. Hold Shift for a perfect square or circle.

    RDOLP

  2. Label it

    Double-click any shape and type. The text wraps to fit and moves with the shape. Double-click empty space for free text.

    Double-clickTEsc

  3. Join with arrows

    Drag an arrow from one shape to another. Its ends stick, so moving a box drags its arrows along with it.

    AClick, click, Enter

  4. Save, export or share

    Keep the editable file, export a PNG or SVG, or copy a link that carries the whole drawing.

    Ctrl SCtrl Shift E

Works with Excalidraw

Same file format, both directions

Sketchpad saves standard .excalidraw files. Open a drawing from excalidraw.com here, or take a Sketchpad drawing back there. Copy and paste between the two works as well.

Library files (.excalidrawlib) import straight into your Sketchpad library.

Features

Everything in the box

draw

  • Rectangle, diamond, ellipse, line, arrow
  • Freehand pencil and text
  • Images by paste, drop or upload
  • Multi-point and closed lines
  • Laser pointer for presenting

style

  • Any stroke and fill colour
  • Hachure, cross-hatch, solid and zigzag fills
  • Three sloppiness levels
  • Dashed and dotted strokes
  • Hand-drawn, normal and code fonts

arrange

  • Move, resize, rotate
  • Group and ungroup
  • Align and space evenly
  • Bring forward, send back
  • Lock things in place

edit

  • Undo and redo
  • Copy, paste, duplicate
  • Copy and paste styles
  • Bend lines, add and remove points
  • Eraser

canvas

  • Infinite canvas, pan and zoom
  • Pinch to zoom on touch screens
  • Grid with snapping
  • Dark mode
  • Personal library of reusable bits

save

  • Autosaves in your browser
  • Save and open .excalidraw files
  • PNG at 1×, 2× or 3×
  • SVG with the font embedded
  • Share links, nothing uploaded

Self-host

Run your own copy

Plain HTML, CSS and JavaScript. There is no build step and nothing to install.

On your computer

Download the repo and open the page.

git clone https://github.com/bhxuk/Sketchpad
open Sketchpad/index.html

On any web server

Upload the folder. Apache, Nginx, IIS or a NAS all work.

/public_html/sketchpad/
  index.html
  css/ js/ fonts/ vendor/

On GitHub Pages

Fork the repo, then turn on Pages for the main branch.

Settings → Pages →
  Deploy from branch → main
